# Standard Bank - Next Best Action Project

## Overview
This repository contains a **high‑performing classification engine** to predict customer churn and a **recommendation engine** that provides product suggestions for churned customers to convert them into non‑churning customers. The deliverables are:

1. `classification_engine.py` – train, evaluate, and export a churn classifier.
2. `recommendation_engine.py` – creates a dummy dataset of churn‑type customers and the best product to offer them.
3. `dummy_recommendations.csv` – the generated recommendation dataset.
4. `generate_presentation.py` – produces a polished PowerPoint (`NextBestAction.pptx`) summarising the methodology, results, and next steps.
5. `requirements.txt` – exact Python dependencies.
6. `README.md` – quick‑start guide.

All scripts are written with reproducibility, clear comments, and best‑practice coding standards (type hints, logging, deterministic random seeds). The PowerPoint is generated programmatically using **python‑pptx** so you get a ready‑to‑share deck without manual editing.
